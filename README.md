# ai-in-api-testing

This repository contains resources for my course AI in API Testing. This course was generously sponosored by ShiftSync and so you can access it for free [here](https://shiftsync.tricentis.com/on-demand-72)

Since the focus of this course is on API testing there are a number of different example APIs in here that you can use as you investigate the best way to use AI in API testing.

There are also resources in here that relate to or expand on concepts in the course

If you have any issues with anything in the course or this repository please file an [issue](https://github.com/offbeattesting/ai-in-api-testing/issues) or reach to me and I will do my best to help!
